// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospace rebalance-bsp [-h|--help] [--workspace <workspace>]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

Windows are sorted by their on-screen position (top-to-bottom, left-to-right) and arranged into a balanced binary tree.
Each split is oriented based on the aspect ratio of the region it occupies: wide regions split horizontally, tall regions split vertically.

This command has no effect if `bsp` is not the active layout for the workspace.
